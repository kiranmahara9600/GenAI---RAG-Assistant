# Onboarding Guide

## Your First Day
- Arrive at 9am and ask for the People team at reception. You'll receive your laptop, access badge, and equipment checklist.
- IT will set up your laptop. This typically takes 1–2 hours.
- You'll have a welcome lunch with your team at noon.

## First Week Checklist
- [ ] Set up company email and Slack
- [ ] Complete security and compliance training (mandatory, due by end of week 1)
- [ ] Read the employee handbook (HR portal > Documents)
- [ ] Schedule 1:1s with your team members
- [ ] Get access to relevant GitHub repositories (ask your tech lead)
- [ ] Set up local development environment (see tech_faq.md)

## Key Tools
| Tool | Purpose | Access |
|------|---------|--------|
| Slack | Team communication | Auto-provisioned |
| Notion | Docs and wikis | Request via IT |
| GitHub | Code repository | Request via tech lead |
| Jira | Project tracking | Auto-provisioned |
| Figma | Design files | Request via design team |

## Who to Contact
- **HR questions:** hr@company.com
- **IT issues:** it-support@company.com  
- **Finance/expenses:** finance@company.com
- **Your buddy:** Assigned in your welcome email

## Probation Period
Your probation period is 3 months. You'll have check-ins at weeks 2, 6, and 12. Feedback is two-way — use these sessions to raise any concerns.
